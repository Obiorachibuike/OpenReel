- **2 Working media engine — initial usable path verified:** real uploads, clip/image assembly, captions, background audio, durable rendering, preview/download. No paid service required. More media sandboxing/retention and advanced transitions/export formats remain.
- **3 AI scripting — initial adapter:** queued Ollama drafts, editable supplied script, paragraph planning. No research/search, script review agent, Hugging Face, or structured storyboard generation.
- **4 Speech/images — not implemented.**
- **5 Generative video — not implemented.**
- **6 Editor — working scene-based first version:** media/caption/duration/order edits, settings, preview, explicit persistence and stale-version checks. No multitrack scrubbing, autosave, undo, narration mixing, advanced effects, or histories.
- **7 Automation — not implemented:** worker durability does not imply a scheduling system.
- **8 Publishing — not implemented:** export/manual publishing only, never false platform success.

Future integrations require official API review, provider capability schemas, licenses, secret storage, budget reservations, timeouts, cancellation, validation, and optional real-provider tests.
